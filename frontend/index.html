Como Funciona

Pipeline de IA
1

Recolha de Dados

NASA FIRMS (fogos em tempo real), OpenWeatherMap (meteo), ERA5 + ICNF (histórico 2000-2023), Copernicus Sentinel-2 (NDVI real por satélite).

2

NDVI por Satélite

O NDVI real é calculado a partir das bandas B04 (vermelho) e B08 (infravermelho próximo) do Sentinel-2, processadas pela API do Copernicus Data Space. Quando indisponível (nuvens, sem revisita recente), usa estimativa sazonal.

3

Treino do Modelo

Random Forest com 500 árvores, 8 features (NDVI, temperatura, humidade, vento, precipitação, mês, latitude, longitude), treinado com 5184 registos reais.

4

Previsão em Tempo Real

IA prediz risco para 16+ cidades portuguesas com 91.4% de precisão. Compara previsão com NDVI real vs. estimado para mostrar o impacto dos dados de satélite.

5

Visualização

Dashboard interativo com mapa, gráficos, alertas visuais e modo de simulação para testar cenários meteorológicos.
